# MCP 파이썬 예제 파일을 만들어줘. Server와 Client 예제를 만들어주고 실행 방법을 알려줘

아래는 **MCP (Model Context Protocol)**를 사용하여 Python으로 Server와 Client를 구현하는 예제입니다. 또한 실행 방법도 포함되어 있습니다.

---

## **MCP Server 코드**

```python
from mcp.server.fastmcp import FastMCP

# MCP 서버 생성
mcp = FastMCP("Example Server")

# 간단한 도구 정의
@mcp.tool()
def add(a: int, b: int) -&gt; int:
    """두 숫자를 더합니다."""
    return a + b

@mcp.tool()
def subtract(a: int, b: int) -&gt; int:
    """두 숫자를 뺍니다."""
    return a - b

# 리소스 예제 정의
@mcp.resource("greeting://{name}")
def get_greeting(name: str) -&gt; str:
    """사용자 이름을 포함한 인사말을 반환합니다."""
    return f"Hello, {name}!"

if __name__ == "__main__":
    # 서버 실행
    mcp.run(transport="stdio")
```

## **MCP Client 코드**

```python
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    # MCP 서버 연결 설정
    server_params = StdioServerParameters(
        command="python",  # 서버 실행 명령어
        args=["server.py"],  # 서버 파일 경로
        env=None  # 환경 변수 (필요 시 추가)
    )

    # 클라이언트 세션 시작
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()

            # 사용 가능한 도구 목록 가져오기
            tools = await session.list_tools()
            print("Available tools:", [tool.name for tool in tools.tools])

            # 'add' 도구 호출
            result = await session.call_tool("add", {"a": 3, "b": 5})
            print("Add result:", result.result)

            # 'greeting' 리소스 읽기
            greeting = await session.read_resource("greeting://John")
            print("Greeting:", greeting.content)

if __name__ == "__main__":
    asyncio.run(main())
```

## **실행 방법**

1. **Python 환경 설정**
    - Python 3.9 이상이 설치되어 있어야 합니다.
    - MCP 패키지 설치:

```bash
pip install mcp[cli]
```

2. **서버 실행**
    - 위의 `server.py` 파일을 생성한 후 다음 명령어로 실행합니다:

```bash
python server.py
```

3. **클라이언트 실행**
    - `client.py` 파일을 생성한 후 다음 명령어로 실행합니다:

```bash
python client.py
```

4. **결과 확인**
    - 클라이언트에서 서버에 연결하고 도구 및 리소스를 호출한 결과가 출력됩니다.
